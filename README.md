# jodo-anime-hub（Windows 免安裝版）

本機動畫站：整理台灣正式代理、在 YouTube 官方頻道免費上架的動畫，以及巴哈姆特動畫瘋的作品資訊。
影片一律用官方嵌入播放器播放，本機不存任何影片。

## 下載與使用

1. 下載 [`jodo-anime-hub-win64.zip`](jodo-anime-hub-win64.zip?raw=1)（Windows 10 / 11，64 位元）。
2. 解壓縮到任何地方（不要直接在 zip 裡面執行）。
3. 雙擊 `jodo-anime-hub.exe`，瀏覽器會自動打開 http://127.0.0.1:8778/

**不需要安裝 Python 或任何東西。**

- Windows 跳出「Windows 已保護您的電腦」：exe 沒有數位簽章，按「其他資訊」→「仍要執行」。
- 網頁全部關掉後程式會自己結束，也可以直接關掉黑色視窗。
- 手機、平板也想看：在資料夾開終端機，執行 `.\jodo-anime-hub.exe --lan`，用畫面上的區網網址連（防火牆請允許私人網路）。

詳細說明見 zip 裡的 `使用說明.txt`。

## 資料

- 收藏 / 觀看進度 / 紀錄：exe 旁邊的 `anime_data.json`
- 片單與快取：exe 旁邊的 `data\`，超過 12 小時會在背景自動更新

換新版時保留這兩個，紀錄就不會遺失。

## 抓不到片單？

YouTube 常改版，exe 內建的 yt-dlp 太舊時會抓不到片單，請下載最新版本。
